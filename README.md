# AI Person Detector (Flask + YOLOv8)

A real-time person detection web app built using **Flask**, **YOLOv8**, and **OpenCV**.

---

## Features
- Real-time webcam detection
- Flask web interface
- FPS counter
- Detects only persons

---

## Tech Stack
- Python
- Flask
- OpenCV
- Ultralytics YOLOv8
- NumPy

---

## How to Run
```bash
git clone https://github.com/<your-username>/ai-person-detector.git
cd ai-person-detector
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```
